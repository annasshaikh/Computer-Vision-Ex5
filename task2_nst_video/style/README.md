# Style Images

Place three style paintings in this folder. Below are suggested public-domain works:

| File | Artwork | Artist | Source | License |
|------|---------|--------|--------|---------|
| `starry_night.jpg` | The Starry Night (1889) | Vincent van Gogh | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:VanGogh-starry_night_ballance1.jpg) | Public Domain |
| `great_wave.jpg` | The Great Wave off Kanagawa (c.1831) | Katsushika Hokusai | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Great_Wave_off_Kanagawa2.jpg) | Public Domain |
| `composition_viii.jpg` | Composition VIII (1923) | Wassily Kandinsky | [Guggenheim](https://www.guggenheim.org/artwork/1924) | Reproductions for educational use |

## Download instructions

```bash
# Starry Night
wget -O style/starry_night.jpg \
  "https://upload.wikimedia.org/wikipedia/commons/thumb/e/ea/Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg/1280px-Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg"

# Great Wave
wget -O style/great_wave.jpg \
  "https://upload.wikimedia.org/wikipedia/commons/thumb/a/a5/Tsunami_by_hokusai_19th_century.jpg/1280px-Tsunami_by_hokusai_19th_century.jpg"

# For Kandinsky, download from the Guggenheim or a public repository and
# save as style/composition_viii.jpg
```

All three images are either in the public domain or reproduced for
non-commercial educational purposes only.
